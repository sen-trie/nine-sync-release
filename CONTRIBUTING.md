# Contributing to NineSync

Thank you for helping. The full guide is [Contributors Wanted](https://ninesync-docs.sentrie.workers.dev/contributors/) in the documentation (source: `zensical/docs/contributors.md`) - this file is the short version. Developers: see the [Developer Guide](DEVELOPER_GUIDE.md).

- **Report problems** in this repository's issue tracker.
- **Change addon code** in the repository that owns it: [nine-sync-core](https://github.com/sen-trie/nine-sync-core) or [nine-sync-fx](https://github.com/sen-trie/nine-sync-fx)
- **Change documentation, packaging or release workflows** here. Docs are Markdown in `zensical/docs/`, with navigation in `zensical/zensical.toml`.
- **Submodules:** Core and FX are submodules pinned per release. Do not edit their files from here.
- **Open an issue first** for anything larger than a small fix.
- **Translations** are `.po` files in each repository's `i18n/` folder; see [Translations](DEVELOPER_GUIDE.md#translations).
- **AI tools** are allowed; you remain responsible for the whole change.
- **Third-party assets:** only submit files you may redistribute, and credit their authors.

By contributing you agree that your work is released under GPL-3.0-or-later.
