# Frequently Asked Questions

**Will NineSync always be free?**
<br/>
Yes. NineSync is intended to remain free. This does not override license conditions for third-party models, effects or other assets.

**Do I have to credit NineSync?**
<br/>
No credit is needed for artwork or animations made with NineSync. If you want to mention or link the project, it helps others find it.

**Can I suggest a feature or report a problem?**
<br/>
Absolutely. See [Reporting and Triage](triage.md).

**Does NineSync send my project data anywhere?**
<br/>
No. Core and FX process project data locally, and the addon doesn't send any files or telemetry to the developer. The FX shared library, `mme_core.blend`, is a local library shared between your projects and is not uploaded online.

**Was AI used to develop NineSync?**
<br/>
Yes. AI was used extensively during development. See the [Disclaimer](disclaimer.md).
