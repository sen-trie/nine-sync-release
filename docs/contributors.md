# Contributors Wanted

NineSync benefits from artists who use it in real projects. You don't need to be a programmer to help.

**Translators:** Help make the interface and documentation accessible in more languages. Coordinate terminology and check translations in context.

**Testers:** Try realistic `.pmm`, `.x` and `.fx` projects, report what works and what doesn't, and share clear reproduction steps. Only share sample assets when you have permission to do so.

Feedback on confusing controls, unclear documentation and rendering differences is welcome too. Open an issue on the [issue tracker](https://github.com/sen-trie/nine-sync-release/issues).
