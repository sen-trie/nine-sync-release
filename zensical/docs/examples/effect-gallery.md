# Effect Compatibility Gallery

See how each effect looks in MMD, just after import into Blender, and after adjustments in Blender. Drag the divider or use the arrow keys to compare the images. Use the button in the corner to open a larger view.

The gallery shows which details carry over and which may need tweaking. See [FX limitations](../manual/fx/index.md#limitations).

## Beamman's Thunder

Beamman's lightning effect uses line, flash, wave and particle passes. Adjust `MainColor` to change the colour while the effect is running.

## Adding an entry

Give each effect its own heading and add its creator and a one-sentence description. Put two `<img>` elements inside the comparison, one for each side. Use images of the same size and aspect ratio.
