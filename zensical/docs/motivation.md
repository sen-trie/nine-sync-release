## For MMD artists

Keep MMD's familiar and approachable animation workflow while using Blender's powerful rendering and scene tools for the final result.

## For Blender artists

NineSync opens up workflows around MMD accessories and **MMEffects (MME)** that were traditionally locked to MMD. Converted motions and effects were built with Blender's features in mind, making it easy to integrate to any project.

## For both

A shared project should not require everyone to abandon their preferred animation tools. NineSync aims to help MMD and Blender artists collaborate on the same production while keeping a consistent rendering pipeline.
